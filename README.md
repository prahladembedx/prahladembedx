## 🚀 Featured Project

### 🌍 [AI-Powered Global Urban Heat Island Analysis and Prediction](https://github.com/prahladembedx/urban-heat-analysis)

An internship-level data analytics and machine-learning project that analyzes how urban design and environmental factors influence heat intensity across **50 global cities (2015–2025)** and predicts land-surface temperature anomalies.

- 📈 Best model: **Random Forest** (R² 0.705, MAE 0.218 °C)
- 🔍 Explainability with SHAP, plus statistical testing and 15+ EDA charts
- 🖥️ Interactive **Streamlit dashboard** with 7 sections, including live ML predictions

**Stack:** Python · Pandas · scikit-learn · XGBoost · SHAP · Plotly · Streamlit
